## 🚀 Biggest Projects

### 🧰 [Exfenc Tools](https://exfenc-tools.vercel.app/)
A free utility workspace with 18 tools that stay out of your way. It includes:
- **Files & images:** file converter (Word, PDF, Markdown, text, images), image compressor, resize & crop, image converter
- **Developer tools:** regex tester, Markdown editor, JSON ↔ CSV, a CS toolkit (JSON formatter, Base64/Hex/URL, hashes, JWT decoder, UUIDs)
- **Design & utilities:** vector illustrator, color picker with WCAG contrast checks, QR code generator and reader, text tools, IP and DNS lookup
- **Online:** media downloader, anonymous browser and an NGL message sender

### 🤖 [OXFEN Bot](https://t.me/OXFEN_bot)
A Telegram bot offering CPM 1 and 2 tools. [Start it on Telegram](https://t.me/OXFEN_bot).
